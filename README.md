# Noach

A Houston environmental planning assistant that connects weather, air quality and bayou conditions to saved places and everyday activities.

[Live demo](https://noach.select) ? [Project documentation](htx-resilience-hub/README.md)

## Built with

- **Gemini API** for contextual environmental guidance.
- **Backboard** for persistent assistant memory and saved preferences.
- **TigerDB / PostgreSQL** for environmental data and account storage.
- **ElevenLabs** for natural spoken responses.
- **Vultr-ready infrastructure** with Docker Compose, continuous workers and Caddy HTTPS. VM deployment is planned.
- **Next.js, React, TypeScript and FastAPI** for the application.

See the [Vultr deployment guide](htx-resilience-hub/README.md#vultr-ready-deployment) for the prepared VM setup.
